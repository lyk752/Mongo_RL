STL模型导出时，通过隐藏其他所有部位，并选中对应的坐标系进行导出。

>    <inertial>
      <origin
        xyz="-0.100012 0.001675 0.006587"
        rpy="0 0 0" />
      <mass
        value="0.283" />
      <inertia
        ixx="0.000158079"
        ixy="0.000006723"
        ixz="0.000008347"
        iyy="0.001815418"
        iyz="-0.000000571"
        izz="0.001786791" />
    </inertial>

该部分第第一项采用质心到对应坐标系原点的距离。
第三项采用由重心决定，并且对齐输出的坐标系，注意改为负张量计数法。

>  <joint
    name="left_hip_joint"
    type="continuous">
    <origin
      xyz="0.00654 0.09181 0.00381"
      rpy="0 0 0" />
    <parent
      link="wlbody" />
    <child
      link="left_thigh" />
    <axis
      xyz="0 1 0" />
  </joint>

该部分均默认continuous后续加限幅，也可以直接设置为旋转关节加限幅。

第一项为该部分坐标系原点与父坐标系原点位移，转轴默认010。
